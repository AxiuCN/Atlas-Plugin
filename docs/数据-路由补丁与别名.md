# 数据口径：补丁层、别名与版本更新记录

> 本册由插件根 `AGENTS.md` 拆出，对应主文件的「四·8 本地补丁层 · 四·9 别名系统 · 四·11 版本更新记录（含原本地主题文档）」；主文件只留快速参考与文档索引。

## 8. 本地补丁层（resources/patch/）

submodule 在 `#图鉴更新` 时会被整体覆盖，故所有数据/图片/索引修正在读取时叠加：

| 目录 | 内容 | 应用点 |
|------|------|--------|
| `data/<与 data/ 相同的相对路径>.json` | 条目补丁：对象递归合并、数组整体替换、标量覆盖（`_patch` 不参与合并） | `loadRecord()`（`loadRawRecord()` 保留原值供比对） |
| `gallery/<game>/<资源名>.webp` | 图片补丁：按 `meta.images[].originalValue` 匹配，补缺图或覆盖错图 | `imgUrl()` / `galleryUrl()` / `resolveRecordImage()` |
| `map.json` | 索引补丁：改条目名/稀有度等索引层字段 | `ensureIndex()` |

```jsonc
{
  "_patch": {
    "note": "源站把翠绿之影 5 个部件的 desc 抓成「砂糖专用」",
    "upstream": { "content.detail.parts.equip_ring.desc": "砂糖专用" },  // 上游原值快照
    "updatedAt": "2026-09-13"
  },
  "content": { "detail": { "parts": { "equip_ring": { "desc": "…" } } } }
}
```

- `_patch.upstream` 点路径与上游当前值不一致（上游已改）→ `logger.warn` + `#图鉴补丁` 列 ⚠，补丁仍生效，需人工复核
- `#图鉴补丁` 是 `permission: all` 的公开命令，展示的补丁路径一律转成**插件内相对路径**（`resources/patch/...`），不回显服务器绝对路径；读写仍用 `components/patch.js` 的绝对路径
- 缓存按相对路径，`reloadIndex()` 一并失效；改补丁后 `#图鉴更新` 或重启生效
- 一文件一条目，便于 diff 与回退；图片补丁几十 KB 量级按需增补


## 9. 别名系统

四层来源（低→高）：外部插件（miao `alias.js` / ZZZ-Plugin `alias.yaml`）→ miao 自定义（`alias_gs.cfg`/`alias_sr.cfg`）→ Atlas 预设（`resources/alias/<game>/<type>.yaml`，入 git）→ Atlas 自定义（`config/alias/<game>/<type>.yaml`，git-ignored）。
按游戏×类别 YAML 分文件、`标准名: 别名1,别名2`，目录扫描自动发现；每次全量重建 Map（跨来源严格覆盖），双向注册。`initAliasWatcher()` 惰性挂载，监听 `resources/alias/` + `config/alias/` + miao 两个 cfg，0.5s 防抖 → `reloadAliasMap()`，手编保存即生效。
命令（`apps/alias.js`，priority 8000）：`#图鉴别名设置 <标准名> <别名>`（可带 `原神/星铁/绝区零` 前缀）、`#图鉴别名删除 <别名>`、`#图鉴别名列表`。权限双闸：rule 固定 master + 函数内 `checkPerm` 按 `config.yaml → alias.set/del/list` 二次判定（group_admin 私聊显式拒绝）。类别定位走 `resolveEntryPageKey`（撞名按 PAGE_PRIORITY 偏主体）；写入走 `CustomAlias`（tmp+rename 原子写 + 写锁）；帮助并入 `#图鉴帮助`。



由插件根 `AGENTS.md` 拆出；主文件只留快速参考与文档索引。

**与后缀剥离的关系（原词是别名就不剥离）**：`resources/alias/gi/artifact.yaml`（预设层，入 git）登记了「名字本身带后缀」的别名，目前有 `火套`（炽烈的炎之魔女）与 `冰封迷途的勇士`（冰风迷途的勇士，修源站/常见错字）；`风套` / `冰套` / `水套` / `岩套` / `草套` / `沙套` / `奶套` 仍来自 miao 的 `setAbbr`。`parseSubView()` 在任何后缀剥离前先查别名表，命中者按原词检索（详见 [`功能与命令.md`](./功能与命令.md) 的后缀一节）。这 8 个名字同时是 `suffix-routing` 套件的断言对象——别名一旦缺失或改名，套件会转红。

## 11. 版本更新记录（`apps/updateLog.js`）

展示后端 diff 的「最新版 vs 前一版」数据变更。触发词 `#版本更新记录` / `#变更项目` / `#新版本改动`（`permission: all`，priority **9000**——**必须早于常规查询 10000**，否则「版本更新记录」会被当成关键词去搜图鉴）；`*` / `%` 前缀经框架标准化为 `#星铁` / `#绝区零`，故三游戏叫法一致。

| 项 | 处理 |
|----|------|
| 数据来源 | `model/VersionDiff.js` 的 `loadVersionDiff(gameId)` 读 `BACKEND_DIR/data/diffs/<gameId>.json`。**本地只保留一份**（最新版 vs 前一版），所以命令不带版本参数；纯本地读取、不联网。后端原文结构 `{ gameId, localVersion, version, fetchedAt, diff: { fromVersion, toVersion, generatedAt, counts, items[] } }` |
| 生成时机 | 由后端 `src/scrape-diff.mjs` 生成，`AtlasUpdater.runDiffScrape()` 只是它的封装（`node src/scrape-diff.mjs --game gi,hsr,zzz`，cwd=BACKEND_DIR、超时 120 s）。调用点是三条流程的**最后一步**：`_doInit`（`#图鉴初始化` / `#图鉴强制初始化`）、`handleUpdate`（`#图鉴更新`）、`autoUpdateTask`（每日 5:00）；失败只 `logger.warn`，不阻断主流程、不影响完成通知。没有 diff 文件时命令回「暂无<游戏>版本更新记录，执行 `#图鉴更新` 后自动生成」 |
| 归一化 | `buildDiffData()` 把原文归一成模板数据：条目按 `entity` 分组（`ENTITY_LABELS` + `ENTITY_ORDER`：角色 / 武器 / 光锥 / 圣遗物 / 遗器 / 驱动盘 / 邦布，未登记的 entity 追加末尾），`section` → 区块中文（`SECTION_LABELS`：基础 / 技能 / 天赋 / 命座 / 星魂 / 行迹 / 属性 / 材料 / 精炼 / 故事 …），`labelKey` → 字段名（`LABEL_LABELS`：名称 / 描述 / 图标 / 稀有度 / 称号 / 属性 / 命途 …）；每组标题带「共 N 条 · 新增 x · 变更 y」 |
| 变更口径 | 文本字段**以 lv1（首个 description）为准**做逐字 diff，切成 `parts[]` 的 `del` / `add` / `same` 三段渲染红删绿增（官方色号映射成内联色）；数值 / 参数行**折叠成计数**（「另有 N 处参数更新」），旧值→新值不可见——扩展示意见本文件末「后续增强」；图标变更另出一对 before → after 缩略图 |
| 渲染与发送 | `renderAtlas('update-log', data, { imgType: 'jpeg', multiPage: true, multiPageHeight: 4000 })`——**返回值可能是数组**：单张直接 `e.reply(img)`，多张按「<游戏>版本更新记录 · i/N」走 `common.makeForwardMsg` 合并转发，一张都没有才回「渲染失败」。`apps/updateLog.js` 是本插件目前**唯一**用 `multiPage` 的调用点（`renderAtlas` 的 `@returns` 即 `Buffer` / `Buffer[]` / `false`） |
| 模板 / 样式 | `resources/atlas/update-log.html` + `common/update-log.css`；hero 走 `hero-plain`（`{{gameName}} · 版本更新记录` / `{{fromVersion}} → {{toVersion}}` / `更新于 {{generatedAt}}`），与其他页面一样吃 `renderScale` 的 zoom。模板里 `each` 循环体**必须无换行无缩进**——`white-space: pre-wrap` 会把模板空白渲染成整片垂直空隙 |
