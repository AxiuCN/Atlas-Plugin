# 功能与命令

> 本册由插件根 `AGENTS.md` 拆出，对应主文件的「一、功能范围 · 四·7 子视图与页面类型后缀 · 四·10 special 触发」；主文件只留快速参考与文档索引。

## 支持

| 维度 | 范围 | 说明 |
|------|------|------|
| 游戏 | 原神 / 星铁 / 绝区零 | 异环（nte）数据在后端存在但未注册 |
| 语言 | 仅简体中文 | 后端支持 en/ja/ko 但未抓取 |
| 功能 | 关键词搜索 + 快捷入口 + 子视图 + 特殊触发 + 管理指令 | `#关键词` / `*关键词` / `%关键词` |
| 搜索评分 | 精确180 → 前缀100 → 包含65 → 反向45（别名打折 155/70/45）+ PAGE_PRIORITY + 二次评分 + 全文兜底 + 文件系统兜底 | 见 `model/AtlasService.js` |
| 多形态角色 | 主角 / 同族多形态按「族名·属性」分形态成条目（旅行者·火…草、开拓者·毁灭…欢愉、奇偶·火…草、三月七·存护/巡猎） | 形态族识别见 `components/protagonist.js`；索引期按数据派生变体名（原神取元素码、星铁取命途码），男女形态折叠为一条，hero 取两形态合体（`.hero-split` + `.hero-split-v` 中间竖线对半）；带性别标记的族另挂社区简称（奇偶 → 偶 / 男偶 / 女偶 / 火偶 / 火男偶） |
| 子视图 / 页面类型后缀 | 角色 7 子视图 + 3 个页面类型后缀 | 子视图只对角色生效；怪物页的「资料/技能/掉落/变种个体」等后缀只用于把查询导向怪物页，不做视图过滤。后缀集合与映射都在 `components/constants.js`，新增必须同步登记；见[数据-功能与命令](./功能与命令.md) |
| 装备类页面 | 武器/光锥/音擎、圣遗物/遗器套装/驱动盘 | 类型/命途进 hero 小方框；部件按槽位排序并标槽位名；见[数据-装备与敌人](./数据-装备与敌人.md) |
| 敌人/怪物页 | 三游戏共用 monster.html，**不分子视图** | 同名记录折叠为一条、变种进「变种个体」栏；`#怪名掉落` / `#怪名资料` / `#怪名技能` / `#怪名变种个体` 等后缀只用于抢先接管并把查询导向怪物页（与 `#怪名` 等价，渲染完整页）；面板按基准等级换算（原神 103 / 星铁 95 / 绝区零 70，标签带等级）；见[数据-数据-装备与敌人](./数据-装备与敌人.md) |
| 版本更新记录 | `#版本更新记录` / `#变更项目` / `#新版本改动`（`*` / `%` 前缀切游戏） | 展示后端 diff 的「最新版 vs 前一版」数据变更，红删绿增；纯本地读取、不联网，见[数据-数据-路由补丁与别名](./数据-路由补丁与别名.md) |
| 管理指令 | `#图鉴初始化` / `#图鉴强制初始化` / `#图鉴更新`（master）、`#图鉴状态`、`#图鉴补丁`、`#图鉴帮助`、`#图鉴别名设置/删除/列表` | 初始化两阶段：环境准备→抓取；别名管理双闸权限 |
| 定时任务 | 每日 5:00 版本检查→增量→重试→全量兜底，完事补抓空缺 | `autoUpdate.enabled/cron/retries/retryDelayMs/timeoutMs/fallbackToFull` |
| 特殊触发 | 成就（列表）、深渊/混沌/防卫战等挑战（最新一期） | 见 `components/constants.js` SPECIAL_TRIGGERS |
| 渲染 | puppeteer 截图，中性灰白 900px，6 种自定义字体；**输出尺寸随 `renderScale` 缩放** | 缩放由模板 `<body style="zoom:{{renderScale}}">` 实现（框架渲染后端不暴露 DPR 旋钮），`renderAtlas()` 注入 `config.yaml → renderScale`（钳制 0.5~3，默认 1.5）——**改它会直接改变所有图的像素尺寸与体积**（实测 900×4340 / 639 KB → 1350×6427 / 1143 KB）。CSS 分域：`resources/common/` base/hero/components/weapon/relic/list/achievement/detail |
| 官方标注 | 描述保留 `<color=#X>` 色相、`<u>` 制度词条、`<i>` 补充注记；模板 `{{@}}` 原样渲染 | `cleanMarkup()`（util.js）：`<color>`→6 位大写内联 span、`<u>`→`.kw`、`<i>`→`.note`，其余标签（unbreak/iconmap/term/icon）剥除；色相映射集中在 `components.css` 官方内联标注段 |
| 数据源 | submodule（fork），纯文件读取 | 不走网络、不依赖 Redis |

## 不支持

分类浏览（无按类别列表）；挑战/成就往期翻页（只最新一期）；多语言。

## 7. 子视图与页面类型后缀

角色 7 子视图（后缀触发，**仅角色 pageKey 生效**；后缀不按游戏过滤，混着叫都认）：

| 后缀（含各游戏叫法） | subView | 行为 |
|------|---------|------|
| 天赋 / 技能 / 行迹 / 忆灵技 / 忆灵 | skills | 技能（完整参数表）+ 固有天赋 + 相关效果（HSR 另有忆灵技能与附加能力栏） |
| 天赋倍率 / 技能倍率 / 倍率表 / 倍率 | rates | 仅技能卡 + 忆灵组，全等级表按每 5 列拆续表 |
| 命座 / 星魂 / 影画 | constellations | 仅命座 + 相关效果 |
| 资料 / 描述 | profile | 基础信息 + 技能名 + 命座名 + 特殊食物 + 服装 |
| 故事 / 语音 | stories | GI stories+quotes；ZZZ partner_info；HSR 无数据 |
| 养成 / 素材 / 材料 / 升级 / **掉落** / 养成素材 / 升级素材 / 升级材料 / 晋阶材料 / 晋阶素材 / 突破材料 / 突破素材 | materials | 养成素材（仅此视图显示素材栏） |
| 变种个体 / 变种 / 变体 | variants | **怪物页专有**：同名折叠后的战斗变种个体列表，每个变种一行（内部代号或 ID + 分类 + 全部属性 + 弱点 + 抗性），见[数据-数据-装备与敌人](./数据-装备与敌人.md) |
| 图鉴 / 无后缀 | null | 默认视图：hero + metaFields + 技能（无参数表）+ 固有天赋 + 命座 + 相关效果；`applyDefaultView` 另外过滤掉 `materials` 与 `stories` 段（后者待米三家资料重建后再放出） |

> **怪物页不做子视图过滤**：`#怪名掉落` / `#怪名资料` / `#怪名技能` / `#怪名变种个体`（含 `变种`/`变体`）这些后缀的作用只是**抢先接管并把查询导向怪物页**，渲染结果与 `#怪名` 完全一致（完整怪物页）。子视图接线见 `handleQuery` 的 `effectiveSubView`：只有 `character` 会把 subView 传给 builder，其余 pageKey 一律传 `null`。
> 怪物 builder 内部虽保留 `pickSections`（`components/sections/monster/common.js`），但当前不会被外部触发，仅作扩展位。

**页面类型后缀**（`PAGE_TYPE_SUFFIXES`）：`圣遗物`→artifact、`遗器`→relicset、`驱动盘`→equipment。三者都只剥离关键词并把搜索结果**收敛**到该 pageKey，不改子视图。
**收敛无命中必须放行**：`handleQuery` 里限定类型过滤后若一条都没命中 → `return false`（消息交给其他插件，如 miao-plugin 的 `#胡桃圣遗物` 角色圣遗物评分）。**不能保留原结果**，否则 `#胡桃圣遗物` / `#胡桃驱动盘` / `#雅圣遗物` 这类会被本插件吃掉并渲染成角色页，miao 永远收不到消息。例：`#绝缘之旗印圣遗物`、`*不老者的仙舟遗器`、`%原始朋克驱动盘`。
两阶段搜索：带子视图后缀先按剥离后的关键词搜；首条命中 `character` 或 `monster` 都直接使用（怪物页对后缀不过滤），否则回退（rates 回退剥离后关键词，其余回退原始关键词）。`SUFFIX_TO_SUBVIEW` 缺映射会落 materials 兜底，故新增后缀必须同步登记。

**泛用套装后缀「套」**（`SET_SUFFIX` + `SET_PAGE_TYPE_BY_GAME`）：三游戏把套装叫成不同名字，故不能写进扁平的 `PAGE_TYPE_SUFFIXES`，改在 `parseSubView(keyword, gameId)` 里按当前游戏取页面类型——原神→artifact、星铁→relicset、绝区零→equipment（`#如雷套` / `*铁卫套` / `%啄木鸟套`），行为与页面类型后缀一致（剥离 + 收敛，无命中同样放行）。已登记进 `SHORTCUT_SUFFIXES`（供 atlasShortcut 抢占），但**必须从 `SUB_VIEW_SUFFIXES` 排除**，否则会落到 materials 兜底。`套` 是弱后缀，实测无副作用：`#皇女套`（角色名 + 套，图鉴无对应套装）与 `#胡桃换绝缘套`（miao 面板换装，同以「套」结尾）都正常放行；`#套`（剥离后为空）与 `#套装`（不以「套」结尾）走原搜索路径，行为不变。


## 10. special 触发

`page_list`（如 `#成就` → 全部条目列表）与 `page_detail`（如 `*混沌回忆` → 最新一期详情），配置在 `components/constants.js` 的 SPECIAL_TRIGGERS，三游戏各自独立。
