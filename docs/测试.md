# 测试

> 本册由插件根 `AGENTS.md` 拆出，对应主文件的「八、测试」与「五·11」；主文件只留命令与摘要。

## 运行

```bash
cd plugins/Atlas-Plugin
pnpm test                     # = node test/run.mjs，任意 cwd 可跑
pnpm test -- --list           # 只列套件
pnpm test -- --filter=cache   # 只跑文件名含 cache 的
```

不启动 Bot，直接跑真实生产代码路径；每套末尾输出 `结果：通过 N / 失败 N`，运行器最后给汇总。

## 前置与跳过

| 前置 | 何时缺 | 怎么补 |
|------|--------|--------|
| 图鉴数据（`tool/nanoka-atlas-backend/.../data/map.json`） | 未初始化 | `#图鉴初始化` / `#图鉴更新` |
| 浏览器（Chromium / Edge） | 没装或非 Windows | 按序自动探测：`ATLAS_TEST_BROWSER` → puppeteer 缓存里的 Chrome for Testing（`~/.cache/puppeteer/chrome/*/chrome-*/chrome(.exe)`，新版本优先）→ 系统 Edge → `/usr/bin/{chromium,google-chrome}`；都没有则跳过渲染类套件。**系统 Edge 156 会把启动进程 exit 0，puppeteer 据此判定启动失败**，故 Chrome for Testing 排在 Edge 之前 |
| git 替身（`test/.test-tmp/fake-git/git.exe`） | 首次运行 | 套件自动执行 `test/fixtures/fake-git/build.ps1` 编译；编不出则跳过 |

**缺前置打印「⏭ 跳过：原因」并以 0 退出**（不算失败）——新克隆的仓库一跑全绿不一定是真的绿，看跳过数。

## 规范

| 要求 | 说明 |
|------|------|
| 命名 | `<主题>.test.mjs`（写被测行为，不用 `check-` / `stage` 之类历史前缀；数据口径类用 `data-<游戏><页面>`） |
| 路径 | 一律经 `test/_helper.mjs` 推导（`pluginRoot` / `appRoot` / `dataDir` / `tmpDir` / `mod()`），**禁止裸相对路径与盘符** |
| 前置 | 用 `requireAtlasData()` 等，缺前置就 `skip('原因')`（exit 0） |
| 断言 | 用 `checker()`（`check(名称, 条件, 附加信息)` + `finish()`）；数量不必多，但要能真的失败 |
| 临时产物 | 只写 `test/.test-tmp/`；**确需临时改 `config/config.yaml` 的必须按原字节/原 MD5 还原** |
| 桩 | 框架全局桩（`logger`/`redis`/`cfg`/`segment`）已收敛在 `_helper.mjs`，套件内不要重复实现 |
| 数据依赖 | 运行时取样，不写死角色名与条目数（图鉴数据在持续增长） |

```js
// test/<主题>.test.mjs 骨架
import { mod, requireAtlasData, checker, installFrameworkStubs } from './_helper.mjs'

installFrameworkStubs()
requireAtlasData()

const { search } = await import(mod('model/AtlasService.js'))
const { check, finish } = checker()

check('关键词能搜到角色', search('gi', '胡桃')?.results?.[0]?.name === '胡桃')
finish()   // 有失败即 exit 1
```

改模板 / 改渲染链时，**至少跑** `render-scale`（模板可编译 + 输出尺寸随 `renderScale` 成比例）。

## 套件清单

**17 套件**，逐套覆盖与前置见 [`../test/AGENTS.md`](../test/AGENTS.md)（进入 `test/` 时自动加载）；设施说明见 [`../test/README.md`](../test/README.md)。

| 套件 | 前置 | 一句话 |
|------|------|--------|
| `alias-loader` | 无 | 别名层：归一化（六种间隔号）、表性质、按游戏过滤与缓存、变体展开、来源覆盖、reload/版本契约、对外门面 `aliasApi` 只读契约、专武索引（官名/别名/全名闭包、多把带修饰词） |
| `variant-family` | 图鉴数据 | 形态族、同名折叠、重名条目 id 别名合并 |
| `suffix-routing` | 图鉴数据 | 子视图 / 页面类型 / 泛用「套」/ 专武后缀的消费与放行（74 例，含专武未收录提示、落点渲染比对与别名+修饰词） |
| `style-scope` | 无 | 页面 CSS 不得定义共享词汇；页面 CSS 只被同前缀模板引用；模板与 CSS 引用资源必须存在 |
| `record-cache` | 图鉴数据 | `loadRecord` LRU、签名自愈、冻结诊断、与现读现套补丁逐字一致 |
| `text-cache` | 图鉴数据 | 全文兜底文本缓存：二次查询 0 读盘、`reloadIndex` 作废、mtime 自愈 |
| `cache-reload` | 图鉴数据 | `reloadIndex()` 后各派生缓存全部换新 |
| `startup-lifecycle` | 无 | 启动编排契约 + 启动清理遗留攻略目录（临时机制，2026-12-14 后随该机制删） |
| `reload-contract` | 图鉴数据 | reload 行为级契约（补丁驱动、可逆、消费侧换新、幂等） |
| `scrape-lock` | 图鉴数据 | 抓取锁：活跃锁拒绝、残留/过期锁清理、8 进程竞争恰好 1 个成功 |
| `render-scale` | 图鉴数据 + 浏览器 | `renderScale` 端到端（模板 zoom、1 与 1.5 输出成比例） |
| `weapon-refine` | 图鉴数据 | 精炼/叠影/音擎天赋合并 + 全量 512 条往返无损 |
| `patches` | 图鉴数据 | 补丁结构、`_patch.upstream` 一致性、误伤检查 |
| `status-page` | 图鉴数据 | `#图鉴状态` 状态页渲染 |
| `error-reply` | 图鉴数据 | 查询异常只回通用文案、细节只进日志 |
| `patch-paths` | 图鉴数据 | 公开命令不回显服务器绝对路径 |
| `smoke-imports` | 图鉴数据 | 18 个模块加载无环、导出面齐全 |
