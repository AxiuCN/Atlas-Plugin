# Hesperides / 赫斯珀里得斯

本目录是 [Hesperides](https://github.com/AxiuCN/Hesperides) 子模块的挂载点（父目录）。

子模块 `Hesperides/` 是 Atlas-Plugin 的数据采集引擎：多数据源（当前为玉璃 alioth.wiki）→ 规范化产物。
插件通过 `tool/Hesperides/Hesperides/data/hesperides/` 读取 `index.json` / `periods.json` / `records/`。

- 仓库协议 / 用法 / 数据契约：见 `Hesperides/README.md` 与 `Hesperides/docs/`
- 迁移进度：见插件 `docs/待办与规划.md` 的「数据后端迁移」一节
